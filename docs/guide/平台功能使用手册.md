# 智数协同平台 - 功能使用手册

> **版本**: v1.31.0
> **更新日期**: 2026-01-29
> **适用对象**: 数据开发人员、项目管理员

**阅读说明**：本文档中的界面示意图用于说明功能布局和操作流程，具体样式以实际页面为准。

---

## 一、平台概览

### 1.1 技术平台

本平台配套的数据仓库技术栈如下：

| 组件 | 技术 | 说明 |
|------|------|------|
| **数据仓库** | SQL Server | 目标数仓，存储各层数据表 |
| **数据同步** | FineDataLink (FDL) | 帆软数据集成工具，负责 ETL 调度 |

平台生成的脚本（DDL、ETL）均基于 SQL Server 语法，同步脚本可直接用于 FDL 节点配置。

### 1.2 功能模块导航

| 模块 | 入口文件 | 功能定位 |
|------|----------|----------|
| 任务池 | Task_Pool.html | 任务发布、认领、提交、归档 |
| 个人工作台 | My_Workspace.html | 我的任务、待办事项 |
| 模型中心 | Model_Center.html | ODS/DIM/DWD 模型管理 |
| 指标中心 | Metrics.html | 业务指标定义与管理 |
| 统计中心 | Statistics.html | 工时统计、任务分析 |
| 业务域管理 | Domain_Manager.html | 业务域与任务类型配置 |
| 文档中心 | Doc_Viewer.html | 规范文档查阅 |
| 资产中心 | Asset_Center.html | 数据资产目录 |
| 用户管理 | admin.html | 用户账号管理（管理员） |

### 1.3 用户角色

| 角色 | 权限说明 |
|------|----------|
| **管理员** | 全部功能，包括用户管理、任务验收、系统配置 |
| **开发者** | 任务认领与开发、模型编辑（仅自己的）、脚本生成 |

## 二、任务管理

### 2.1 任务池

**入口**: 导航栏 → 任务池 或直接访问 `Task_Pool.html`

#### 流程指引面板

页面顶部有**流程指引面板**（可折叠），分为两种角色视角：

| 角色 | 流程步骤 |
|------|----------|
| **开发者** | 领取任务 → 模型注册/确认 → 开发调试 → 提交验收 |
| **发布者** | 模型规划 → 发布任务 → 进度跟踪 → 验收审核 |

> 点击「模型注册/确认」步骤可直接跳转到模型中心。如果任务已关联模型，可跳过此步骤。

#### 功能清单

| 功能 | 操作方式 | 权限要求 |
|------|----------|----------|
| **发布任务** | 在发布区域填写信息并点击「发布任务」 | 管理员/发布者 |
| **批量导入** | 点击「批量导入」→ 上传 Excel | 管理员/发布者 |
| **认领任务** | 在待认领列表点击「认领」 | 所有用户 |
| **分配任务** | 点击「分配」直接指定负责人 | 管理员/发布者 |
| **查看详情** | 点击任务卡片展开详情抽屉 | 所有用户 |
| **筛选任务** | 使用顶部胶囊标签按类型过滤 | 所有用户 |
| **提交任务** | 进行中任务点击「提交」 | 任务负责人 |
| **确认归档** | 已提交任务点击「通过」或「打回」 | 管理员/发布者 |
| **存疑标记** | 将任务标记为「存疑」并说明原因 | 管理员/任务负责人 |

#### 任务状态流转

```
待认领(OPEN) → 进行中(CLAIMED) → 已提交(DONE) → 已归档(ARCHIVED)
     ↑              ↓                  ↓
     └──────────────┴─── 打回修改
                    ↕
               存疑(ON_HOLD)
```

#### 任务类型说明

| 类型 | 代码 | 颜色标识 | 适用场景 |
|------|------|----------|----------|
| ODS同步 | ODS_SYNC | 蓝色 | 源系统数据同步到 ODS 层 |
| DIM开发 | DIM_DEV | 橙色 | 维度表开发（SCD1/SCD2） |
| DWD开发 | DWD_DEV | 绿色 | 明细宽表开发 |
| ADS报表 | ADS_RPT | 紫色 | 应用层报表开发 |
| 数据运维 | DATA_FIX | 灰色 | 数据修复、补数等运维任务 |

#### 功能边界

| 能做 | 不能做 |
|------|--------|
| 创建、编辑、删除任务 | 批量删除任务 |
| 按状态/类型/负责人筛选 | 跨项目任务管理 |
| 任务关联模型 | 任务依赖关系配置 |
| 任务工时记录 | 甘特图展示 |

**入口**: 导航栏 → 指标中心 或直接访问 `Metrics.html`

#### 功能清单

| 功能 | 说明 |
|------|------|
| 指标定义 | 创建业务指标（名称、口径、公式） |
| 指标分类 | 按业务域/主题分类管理 |
| 指标状态 | 草稿/已发布/已废弃 |
| 指标关联 | 关联到具体的数据模型字段 |

#### 功能边界

| 能做 | 不能做 |
|------|--------|
| 定义指标元数据 | 指标自动计算 |
| 指标分类管理 | 指标血缘追踪 |
| 指标状态流转 | 指标实时监控 |

## 七、文档中心

### 7.1 文档中心

**入口**: 导航栏 → 文档中心 或直接访问 `Doc_Viewer.html`

#### 文档分类

左侧导航按三层分组展示，以分隔线区分：

**核心文档**

| 分类 | 路径 | 说明 |
|------|------|------|
| 数据标准与规范 | docs/standard/ | 编码规范、命名规范、术语定义 |
| 架构决策记录 | docs/decision/ | ADR 文档，记录设计决策与理由 |
| 业务需求 | docs/req/ | 开发需求说明书 |
| 数据模型设计 | docs/design/ | 模型设计文档 |

**参考文档**

| 分类 | 路径 | 说明 |
|------|------|------|
| 解决方案 | docs/solution/ | 技术方案、架构设计 |
| 平台技术 | docs/tech/ | 平台技术说明 |
| 数据字典 | docs/dict/ | 数据字典文档 |
| 使用指南 | docs/guide/ | 平台功能手册（本文档） |

**辅助文档**

| 分类 | 路径 | 说明 |
|------|------|------|
| 培训资料 | docs/training/ | 工具培训、操作指南 |
| 资源模板 | docs/templates/ | 模板文件 |

#### 功能特点

- 自动扫描 docs/ 目录下的 Markdown 文件，按分类分组展示
- Markdown 实时渲染，支持代码高亮
- 支持 HTML 嵌入（如本文档的 UI 示意图）及标签页切换交互
- 左侧导航栏支持分组分隔线，视觉层次清晰

## 八、系统管理

### 8.1 用户管理

**入口**: 导航栏 → 管理 → 用户管理 或直接访问 `admin.html`

**权限要求**: 仅管理员可访问

#### 功能清单

| 功能 | 说明 |
|------|------|
| 用户列表 | 查看所有用户账号 |
| 新建用户 | 创建新账号，设置角色 |
| 重置密码 | 重置用户密码 |
| 禁用/启用 | 账号状态管理 |

### 8.2 数据库连接管理

**入口**: 模型中心 → 设置 → 数据库连接

#### 连接类型

| 类型 | 用途 |
|------|------|
| **数仓连接** | 目标数据仓库（用于验收、DDL 执行） |
| **源系统连接** | 业务系统数据库（用于字段获取、数据对比） |

### B. 常见问题

| 问题 | 解决方案 |
|------|----------|
| 模型编辑按钮无响应 | 检查是否为该模型的负责人 |
| 验收失败：表不存在 | 先在数仓执行 DDL 建表 |
| 派生字段表达式报错 | 检查关联表别名是否正确 |
| 页面加载缓慢 | 尝试刷新页面或清除浏览器缓存 |
