新建协作单

业务方在集团 OA 提交的取数申请流程号。一个 OA 流程对应一个协作单（系统强制唯一）。
开发交付的 SQL 将在此库执行。下拉为空时联系管理员在「系统设置 → 数据库连接」配置 source 类型连接。
外包负责人，由其在平台内将协作单指派给具体开发。下拉显示全部活跃用户（含 admin 兜底），凭备注辨识。
最多 5 个文件 / 单文件 ≤ 10MB / 支持 PNG·JPG·GIF·WEBP。OA 截图、对话截图、邮件截图等均可（选传）。
单个 Excel 文件（.xlsx / .xls），≤ 10MB。用于需求方以具体表格形式描述列名/示例数据，便于开发理解需求。

作废协作单

⚠️ 作废后此协作单将从列表消失，对接人/开发不再可见。此操作不可恢复，仅 admin 可在"显示已作废"筛选下找到。

归档协作单

📁 归档后此协作单将进入只读历史状态。开发不可再修改/重传交付物，仅 admin 可继续操作。归档与"作废"不同——归档是已完成的入库存档。

上传交付物

扩展名 .sql / .txt，单文件 ≤ 1MB。脚本将在目标业务库执行 smoke test。
扩展名 .xlsx / .xls，单文件 ≤ 100MB。在本地跑出来的取数结果，供业务方验收对照。
提交后系统会对 SQL 脚本做 4 层防御 smoke test（语法解析 / 黑名单 / 只读校验 / 真连业务库试跑）。验收通过协作单进入 DONE，否则停留 SUBMITTED 状态并显示错误，可继续重提。
