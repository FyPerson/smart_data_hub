新建修正单

OA 流程号须为 1-20 位纯数字（如 364265）；留空则视为信息技术部自发现。
填写了真实 OA 流程号，须随建单同步上传截图留档（建单后不可补传，事后如需变更请联系信息技术部）。
合并原"错误描述 + 期望值"——把"错在哪 + 要改成什么"写在一起。
批量数据修正必填，须 ≥2（仅 1 条请改用单数据修正）；单数据修正系统固定为 1，无需填写。
勾选后一次建两单（系统1=主单 + 系统2=关联单）：业务方/类型/原因/期望时间共享，两单均待指派——建后在各自详情页指派开发（建单时不直派）。
系统2（关联单）
主业务方姓名必填；同一修正诉求可能涉及多个业务方，完成后逐个发钉钉通知（需手机号）。
可选，业务方期望完成时间（建单人代填）；不填则系统按默认规则生成。
下拉为全部非查看者用户，凭备注辨识；选定后建单即指派，需在详情页手动点「通知开发」发送钉钉。
建单后记录对接人，需在详情页手动点「通知对接人」发送钉钉；对接人收到后在平台指派。
待修复数据附件（表格清单为主，图片/PDF/xlsx，≤5 个文件）+ 选填文字备注；建单后两步上传到本单（上传失败不影响建单，详情页可补传）。

回复预计完成时间

回复后单进入「修正中」；钉钉通知业务方需在详情页手动点「通知业务方·预计」发送。

追加关联单

在本单（主单）上追加一张其他系统的关联单——同一诉求需在多个系统分别修正时使用。业务方、原因、类型、期望完成时间继承主单；新单待指派，追加后在其详情页指派开发。

重修提交

🔄 返工子单：结果证明截图 + 本次说明（≥5 字）均必填。

补充附件

仅补充证据留存，不改变状态、不计入提交次数。单次最多 5 个文件、每个 ≤20MB。

归档修正单

本单发起过拉群讨论（有摩擦），归档须填写摩擦原因。
提示：尚未发送完成通知给业务方，确认要直接归档吗？

行政闭环

行政闭环用于「开发迟迟未处理 / 线下已处理 / 需强制收口」的未完成单，记账式归档，不要求走「完成→归档」。归档方式标记为「行政闭环」，与正常完成单区分。
